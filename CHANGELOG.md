# Changelog

## 0.1.0 - 2026-10-07

Initial reviewed software release.

- Provides a local browser application, Python pipeline, and feature-extraction API for cyclic-voltammetry data.
- Records unit checks, curve descriptors, source-aware validation, and exportable diagnostics.
- Includes scientific-integrity and data-curation tests.
- Review verification: 25 Python unit tests passed; JavaScript test suite run as part of release verification.
- Scope limitation: this release is a reproducible software tool and exploratory workflow, not evidence of universal material identification or definitive model performance.
- Generated datasets, outputs, local environments, and manuscript bundles are not included in the source release.
