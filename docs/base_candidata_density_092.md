# Base candidata de densidade 0.9.2

Foi criada uma base intermediária para a próxima auditoria. Ela reúne as
curvas nativas de densidade da release 0.9.2 e as três curvas de Pt convertidas
de corrente usando área declarada. Corrente absoluta sem área e todos os
membros da duplicata exata conhecida foram excluídos.

Essa base não substitui `scientific_v2`, não cria teste e não produz resultados
do artigo. Antes da validação, ainda é necessário revisar estratos de referência,
independência por DOI, condições das curvas e partição por fonte.

Arquivo: `outputs/density_candidate_0_9_2_v1/atributos_density_candidate.csv`.
